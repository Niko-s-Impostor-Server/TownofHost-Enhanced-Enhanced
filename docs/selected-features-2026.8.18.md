# A、B、E、F、G、H、I、J 实现说明

目标版本为 Itch Among Us 2026.8.18；功能提交 `aba8b7074` 使用显示版本 `2.1.1-au20260818.2`、
程序集版本 `2026.1005.211.2`。随后的 uint32 RPC 协议更新将两者末位升级为 `.3`。
本次基于当前移植分支重新实现选中的功能，没有整批移入上游提交。
版本变化也会更新已有版本派生的 Mod GUID；房间内模组客户端应使用同一构建。

| 项目 | 使用方式与范围 |
| --- | --- |
| A 原版职业 | 职业池新增“侦探（原版）”与“毒蛇”。可设置嫌疑人数上限和尸体溶解时间，通过当前逐玩家游戏选项同步；原有自定义侦探保留。自由练习的原版与模组职业入口均有映射。 |
| B 预设分享 | 本地房主在大厅 `/save 名称`、`/load 名称`，文件位于 `TOHE-DATA/Presets/*.preset`。分享模组选项，包含全局模组选项，不包含原版设置。版本及完整选项结构必须匹配，导入失败回滚。详见 [预设说明](preset-sharing.md)。 |
| E 房间浏览 | 服务器下拉列表多列排列；公开房间列表至少容纳 10 行并滚动，显示房主与房间码，保持原生选择与连接流程。没有新增模组房间过滤协议。详见 [界面说明](room-browser.md)。 |
| F 标签与授权 | 房主编辑 `TOHE-DATA/LocalPlayerTags.json`，用 `/tags reload` 重载。大厅标签支持渐变；`moderate`、`chat`、`end`、`execute` 分别控制踢出/封禁、广播、结束和处决。指定 GM 仅作用于 Standard 分配，不自动授予权限。详见 [配置示例](local-player-tags.md)。 |
| G AFK 与画面恢复 | 挂机检测默认关闭；可配置提醒、保护、提醒后移出房间。房主 `/afk status [编号]`、`/afk exempt 编号`、`/afk include 编号`。`/fixblack [编号]` 刷新兼容模组客户端的镜头与 HUD；详见下文。 |
| H 首刀冷却 | “修复首刀冷却”下增加“覆盖首刀冷却”。关闭覆盖时沿用对应职业的冷却，保留开场后的同步方式。 |
| I 隐藏转换 | “禁止隐藏角色转换”禁止 Jester→Sunnyboy、Arrogance→Bard 的随机替换；不影响显式选择的职业和 Mini 分支。默认关闭，保留既有行为。 |
| J 附加职业短名 | 支持关闭、总是、仅会议、仅会议外；名称前缀、HUD、会议与结果文本统一按上下文选择，缺少短名时按 Unicode 文本元素截取。默认关闭。 |

远端玩家使用新增管理命令时可沿用 `/cmd` 通道。文件命令与权限文件重载只允许本地房主；
普通授权管理员不能操作房主文件。非法权限文件立即撤销该文件的授权，保留内置身份规则。

## G 的修复边界

AFK 状态按会话和玩家对象身份隔离；开场、会议、爬梯、钻洞、移动平台、不可移动状态与
游戏暂停不会正常累计挂机时间。恢复活动解除提醒和保护。详情见 [AFK 说明](afk-monitor.md)。

`/fixblack` 只用于任务阶段已经结束正常过渡后遗留的全黑遮罩/镜头或 HUD 状态。
它不会重建角色、伪造死亡/复活、传送玩家或修改任务、冷却和移动权限。职业黑屏、小游戏、
梯子/钻洞动画以及非本人的观察镜头会拒绝恢复。远端调用走房主授权的 RPC 123 信封，
每个目标间隔 5 秒；返回“已请求”不代表目标已经确认修复。
原版客户端没有本地画面恢复接口，本实现明确拒绝远程修复原版客户端。
