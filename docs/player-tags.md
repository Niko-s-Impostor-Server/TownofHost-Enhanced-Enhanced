# 房主本地玩家标签

房主可以给房间里的玩家设置只保存在自己设备上的标签。标签显示在玩家名字前面；其他玩家通过房主发送的名字更新看到它。标签只改变显示，不授予管理命令权限、GM 身份或反作弊豁免。

## 在游戏中添加或删除

房主输入：

```text
/addtag <玩家编号> <六位十六进制颜色> <标签文字>
/deletetag <玩家编号>
```

例如，`/addtag 3 33CCFF 测试标签` 会给编号为 3 的玩家添加浅蓝色标签。`/createtag` 与 `/addtag` 相同。添加命令在游戏和大厅都能使用；名字中的标签在大厅显示。删除命令只能在大厅使用。玩家必须仍连接在当前房间，且有好友码。

颜色写成六位 RGB 十六进制，不带 `#`，例如 `FF00AA`。颜色或参数无效时，命令会提示用法，不会保存标签。对同一玩家再次使用 `/addtag` 会替换原标签。`/deletetag` 会删除这位玩家的本地标签。

## 手动编辑标签文件

首次成功添加标签后，游戏目录中会出现 `TOHE-DATA/tags.txt`。这是房主设备上的文件，不会上传给其他房主。每行按“好友码=带颜色的标签”保存，例如：

```text
sampleuser#1234=<color=#33CCFFFF>测试标签 </color>
otheruser#5678=<color=#FF00AAFF>活动主持人 </color>
```

等号只在好友码后面的第一个位置充当分隔符，因此颜色标记和标签文字中的 `=` 可以正常读取。手工编辑后，房主在大厅输入 `/tags reload` 即可刷新显示；重新开房也会重新加载。删除文件中的某行并重载，会移除该玩家的标签。文件不存在时不会自动给任何人加标签。

`LocalPlayerTags.json` 已停用，里面的数据不会迁移。旧的 `TOHE-DATA/Tags/<好友码>.txt` 自定义标签也不再作为这个功能的输入；MOD/VIP 等现有专用标签设置仍按原有规则工作。

房主的开发者、MOD 或 VIP 标签可以与本地标签同时显示。如果启用了“隐藏所有标签和文字”，本地标签也会隐藏。

## 与 EHR 的关系

命令形式、`好友码=标签` 文件格式和名字前的显示方式参考了 EHR。本模组读取文件时按第一个 `=` 分隔，确保 `<color=#...>` 标签在重开房间后仍能加载。为避免把外观设置变成安全授权，本地标签不会像 EHR 那样使玩家获得反作弊豁免；好友码也从当前连接的玩家所有者读取，以免过期的玩家对象匹配到错误标签。
